# Report Builder 2.0 — clickable prototype

Static prototype for user testing. Open `index.html`.

- `index.html` — Report Builder (gallery, templates, report editor, Trending High view)
- `trending.html` — standalone Trending High+ CVEs page (links into `index.html`)

## Hosting on GitHub Pages
Upload the **contents of this folder** to the repo root (keep the folder structure and the
`.nojekyll` file — without it Pages/Jekyll drops some asset paths), then
Settings → Pages → Source: `main` / `/ (root)`.
